# Contributing

We welcome contributions to this project. To contribute:

1. Open an issue to discuss the change you would like to make.
2. Fork the repository and create a feature branch.
3. Make your changes, keeping descriptions and code style consistent with the existing files.
4. Open a pull request with a clear description of the change.

Before submitting, ensure that:

- Terraform configurations pass validation (`terraform validate`);
- Documentation stays in sync with the code;
- No credentials or secrets are committed.

For security-related issues, please report them privately to the maintainers rather than opening a public issue.
